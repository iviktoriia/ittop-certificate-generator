Веб-приложение для массового создания и скачивания именных сертификатов об окончании учебных программ «МКА5» и «Первый Шаг» Малой Компьютерной Академии ТОП.

## ✨ Возможности

- 📝 **Два типа сертификатов** — для программ «МКА5» и «Первый Шаг»
- 👥 **Массовая генерация** — вставьте список имён и сертификаты создадутся автоматически
- 🎨 **Уникальный дизайн** — логотип, подпись, год и стилизованный фон для каждой программы
- 📄 **Скачивание в PDF** — все сертификаты одним файлом, готовые к печати
- 🖼️ **Скачивание в PNG (ZIP-архив)** — каждый сертификат отдельным изображением
- ❌ **Удаление отдельных сертификатов** перед финальным скачиванием
- 📱 **Адаптивный дизайн** — корректно отображается на всех устройствах

## 🛠️ Используемые технологии

- HTML5 / CSS3
- JavaScript (ES6+)
- [html2canvas](https://html2canvas.hertzen.com/) — рендеринг DOM в изображение
- [jsPDF](https://github.com/parallax/jsPDF) — создание PDF-файлов
- [JSZip](https://stuk.github.io/jszip/) — упаковка PNG в архив
